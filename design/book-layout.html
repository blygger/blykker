Chapter One

Introduction

Placeholder text shows the typesetting, not the book. The opening paragraph takes a drop cap and small capitals; later paragraphs are indented, not spaced, as in print. An endnote marker sits here1, and a reference is cited inline as Rao 2026.

Paragraphs set to a 34rem measure, with hyphenation on. Index terms like hardness are marked in the source with an invisible line after the paragraph, so the reader never sees them; they turn up in the index with a link back to this chapter.

A section heading

After a heading, the first paragraph is not indented and has no drop cap.
